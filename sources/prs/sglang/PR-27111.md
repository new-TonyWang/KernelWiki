## Summary
On ROCm 7.0 with gfx950 (MI355X), the current code forces all non-tuned FP8 block-scale GEMM shapes to use the Triton kernel. 
This PR adds a fallback to the CK (`gemm_a8w8_blockscale`) kernel for non-tuned shapes, which is significantly faster than the generic Triton path for MoE model
