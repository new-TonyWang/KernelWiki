## Purpose

Currently FP4 quantization logic for `_fused_indexer_q_rope_mxfp4_kernel()` and `_fused_kv_compress_norm_rope_insert_indexer_mxfp4_attn()` does a linear search, which is inefficient, and more importantly, does not do round-to-nearest-even correctly. This PR switches to inline PTX `cvt.
