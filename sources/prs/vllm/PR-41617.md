## Purpose
Fixes #40905 

When running Mamba-based models (Mamba/Jamba) with ultra-long sequences (verified at 1.4M tokens), the _causal_conv1d_fwd_kernel triggers a CUDA Illegal Memory Access (IMA). 

The root cause is an integer overflow in the Triton kernel's pointer offset calculation. Spec
