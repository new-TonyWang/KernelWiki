## Summary

## Purpose

For NVFP4 dense and MoE methods, we were producing "swizzled" weight blockscales and storing them in a new parameter without deleting the original blockscale in process_weights_after_loading. This PR writes those swizzled scales into the same parameter so we don't keep the original data 

## Problem

[Perf] Remove duplicated NVFP4 blockscales to save memory
