## Summary

We can use Sm90AuxStore to customize writing the D tensor (e.g. scatter the D tensor to multiple pointers). In such cases, it is necessary to remove the original writing logic of the D tensor. This PR allowes passing a nullptr for ptr_D to make storing-to-D a noop.

## Problem

Support ElementD to be void for tma
